### Deploy karne ka sahi tarika

```bash
# Step 1 — local se push karo
git push origin main

# Step 2 — VPS pe build karo (HAMESHA rm -rf .next pehle karo)
ssh -i ~/.ssh/staysvacation_deploy root@200.141.2.70 \
  "cd /var/www/staysphere.imagesque.com && git pull origin main && rm -rf .next && npm run build"

# Step 3 — PM2 restart (sirf build complete hone ke BAAD)
ssh -i ~/.ssh/staysvacation_deploy root@200.141.2.70 "pm2 restart staysphere"
```

> **Important:** `rm -rf .next` hamesha karo warna ENOENT build errors aate hain. PM2 build complete hone se pehle restart mat karo.

## Image Rules — IMPORTANT

**VPS pe Next.js image optimizer kaam nahi karta external URLs ke liye.**

**Rule:** Koi bhi `<Image src="https://...">` component mein `unoptimized` prop HAMESHA add karo.

```tsx
// ✅ Sahi tarika
<Image src={property.images[0]} alt={title} fill unoptimized />

// ❌ Galat — VPS pe break ho sakta hai
<Image src={property.images[0]} alt={title} fill />
```

Ye sirf external URLs pe apply hota hai (Unsplash, `img.staysvacation.com`, Elivaas images). Static `/public/` files ke liye zaroorat nahi.

## Elivaas API — Live Prices

**File:** `lib/elivaas-rates.ts` (server-side only)

- Sandbox URL: `https://sandbox.elivaas.com/v1/properties/rates`
- API key env var: `ELIVAAS_API_KEY` (`.env.local` mein hai)
- Channel ID env var: `ELIVAAS_CHANNEL_ID` = `chnl_B6QBF6ArzneqjX`

**Kaise kaam karta hai:**
1. User `/properties?checkin=YYYY-MM-DD&checkout=YYYY-MM-DD` URL pe dates deta hai
2. Server-side `fetchLivePrices()` call hoti hai
3. API se real-time per-night price aati hai
4. `starting_price === 79152` wale results filter ho jaate hain (fake placeholder)
5. Cards pe "from ₹X/night" show hota hai

**Without dates** → prices nahi dikhte  
**With dates** → Elivaas API se live prices
